## 一、监测指标概览

江苏华信土地房地产评估造价咨询有限公司网站建设与内容部署项目生成式引擎优化（GEO）服务合同的附录一设计了监测指标体系, 由四个指标构成:

| 指标 | 核心问题 | 定义 |
|------|----------|------|
| **实体存在度** | 品牌是否被提及？ | 品牌名在AI回答中出现的频率 |
| **语义指纹一致性** | 在LLM的回复中是否引用了网站中对于术语的定义？ | 术语表述与标准术语的匹配程度 |
| **归因准确性** | 内容来源的归属是否准确？ | LLM回复中引用的知识的归属正确性 |
| **引用深度** | LLM在回答中对网页内容引用的程度如何？ | 浅层/中层/深层引用的分布 |

## 二、指标概念详解

### 2.1 实体存在度

**定义**
实体存在度表示LLM在智能搜索过程中品牌的可检索性, 它是LLM在问答过程中能否使用官网相关事实进行回答的基础.

**衡量方式**
实体存在度通过LLM智能搜索过程中访问到华信官网的次数占比进行衡量.

**量化方式**

```
实体存在度 = 成功检索到官网的问题数 / 总探测问答数 × 100%
```

每次问答中, LLM只要访问了华信官网域名白名单（如 `jshuaxin.net`）则视为成功检索.

#### 辅助指标：品牌提及度

在实体存在度检测过程中, 同时统计正文中出现品牌名全称/变体的次数, 用于辅助判断AI是否在回复中提及了品牌.

**品牌名变体表与置信度机制**：

根据变体是否能唯一确定锁定目标品牌进行分类：

| 置信度 | 变体 | 说明 |
|--------|------|------|
| **确定** | 江苏华信土地房地产评估造价咨询有限公司 | 完整全称，能唯一确定 |
| **确定** | 江苏华信土地房地产评估造价咨询 | 去"有限公司"，能唯一确定 |
| **确定** | 华信土地房地产评估造价咨询 | 无地域, 但含完整业务描述 |
| **确定** | 华信土地房地产评估造价咨询有限公司 | 无地域, 含完整业务描述 |
| **确定** | 江苏华信土地房地产评估 | 部分业务关键词+地域 |
| **确定** | 江苏华信造价咨询 | 部分业务关键词+地域 |
| **有歧义** | 华信土地房地产评估 | 只含部分业务关键词,无地域信息 |
| **有歧义** | 华信造价咨询 | 含部分业务关键词, 无地域信息 |
| **有歧义** | 江苏华信咨询 | 业务关键词放宽到"咨询" |
| **不能确定** | 江苏华信 | 存在大量同名企业（如江苏华信新材料、江苏华信制药等） |
| **不能确定** | 华信评估 | 存在同名企业 |
| **不能确定** | 华信造价 | 存在同名企业 |

**置信度判定规则**：
- **确定**：包含完整业务描述（如"土地房地产评估造价咨询"），能唯一锁定目标企业
- **有歧义**：包含部分业务关键词（如"造价咨询"、"土地房地产评估"），较可能是目标企业，但也可能指其他企业
- **不能确定**：只有品牌名或简称，存在大量同名企业，无法确定是否指目标企业

### 2.2 语义指纹一致性(未确定, 还需要完善)

语义指纹一致性表示LLM在回复中复现品牌标准术语的准确程度, 它是品牌核心概念在AI认知中"保真度"的体现.

语义指纹一致性通过比对AI回复中出现的术语与素材库中标准术语的匹配程度进行衡量.

**量化方式**：
```
语义指纹一致性 = 精确匹配术语数 / AI回复中相关术语总数 × 100%
```

术语判定依据来自 `knowledge_base.json` 中的 `terms` 字段, 每个术语包含标准表述 (`standard`) 和常见叫法 (`aliases`). 精确匹配指与标准表述逐字一致, 模糊匹配指与常见叫法一致.

---

### 2.3 归因准确性

**定义**
归因准确性表示LLM在回复中引用搜索得到的事实性内容时, 关于官网内容的出处标识是否准确, 它是官网内容"可追溯性"的体现.

**衡量方式**
归因准确性由人工审查判定. 审查主要针对AI回复事实是否来自官网内容, 检查两个方面:
1. 引用的这些内容与官网原始内容的一致性
2. 是否存在错误归因的情况

**审查流程**：
1. 运行 `entity_existence_monitor.py` 进行实体存在度测试
2. 测试完成后自动生成归因审查文件（`attribution_review_*.json`）
3. 人工审查每条回复:
   - 确认AI访问了哪些页面（`opened_urls`）
   - 如果包含华信官网, 则进入下一步
   - 对照回复内容（`response_text`）, 检查AI回复中的事实性内容是否来自官网内容, 以及是否被正确归属

**输出结果**：
- 每个问题的归因判断：`正确` / `错误` / `无法判断`
- 如有错误, 记录具体问题（如"将江苏华信新材料的内容归到江苏华信土地房地产评估造价咨询有限公司"）

**注意**：归因准确性不是数值指标, 不计算百分比, 而是逐条记录人工审查的定性判断结果.

---

### 2.4 引用深度

**定义**
引用深度表示LLM在回复中引用官网内容的丰富程度, 它反映品牌在AI认知中的"权威程度".

**衡量方式**
通过检测LLM回复中引用官网内容的模式进行分层, **仅在实体存在度命中后计算**（即LLM访问了华信官网或正文中提及了品牌名变体）.

**层次定义**：

| 层次 | 判定条件 | 示例 |
|------|---------|------|
| **浅层** | 仅出现品牌变体 | "江苏华信土地房地产评估造价咨询是专业公司" |
| **中层** | 品牌变体 + 服务关键词 | "华信造价咨询提供净化工程服务" |
| **深层** | 品牌变体 + 数据模式或专业术语 | "根据华信土地房地产评估造价咨询数据, GMP车间造价约3000元/㎡" |

**量化方式**：
```
引用深度分布 = 浅层占比 / 中层占比 / 深层占比
```

**判定规则**：
将LLM回复按换行符分割为段落，每个段落独立判断; 只有"确定"和"有歧义"置信度的变体才被视为有效（排除"不能确定"）,不能确定的变体可能指代的不是网页的内容.
在每个包含有效品牌变体的段落中，检测是否同时包含服务关键词、数据模式或专业术语.

**判定依据**（来自 `knowledge_base.json`）：
- **服务关键词**：`services` 字段中的服务类型
- **数据模式**：`data_points` 字段中的具体数值（金额、面积、百分比等，排除纯时间）
- **专业术语**：`terms` 字段中的标准术语及别名

这些判定依据来源于网页中的"专业洞察"栏目下的各个子栏目的内容.

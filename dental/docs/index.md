# 三个子任务：执行逻辑与原理

本文记录 Apex（根尖点）、Alveolar Crest（牙槽骨脊顶）、CEJ（釉牙骨质界）三个子任务的执行流程与背后的原理。

---

## 0. 共享几何信息准备

三个任务都需要统一的**牙根方向**和**哪里是根侧**的判断。这一层能够产出下列信息供三个任务复用。

### 0.1 PCA 主轴

对单牙 mask 的全部体素坐标做协方差分析，取最大特征值对应的特征向量作为**无向主轴**。

牙齿在冠-根方向上的延伸通常最长，PCA 第一主轴自然捕获该方向。但特征向量没有正负号，因此这一步无法确认哪一端是根尖的方向。

### 0.2 用颌骨给主轴定向 → 根尖方向 和 "根侧"方位（root_filter_mask）的确定

提取牙体表面，计算每个表面点到对应颌骨的距离，取距离最近的一批点（按距离取最近的 15% 分位；若不足 20 个，则补足到最近的 20 个），把这些点投影到 PCA 主轴上。若投影中位数落在正侧，则根方向取 +主轴，否则取反。这个判断的依据是：**离对应颌骨最近的一批牙体表面点位于牙根侧**。

在牙体内部取"到颌骨表面距离 ≤ 2mm 的体素"，作为"根侧候选区"。这样可以把后续搜索范围圈定在根侧.

### 0.3 轴向投影范围 axis_projection

把全牙体素沿 root_direction 投影并归一化到 [0, 1]，1 表示最靠根端。

## 1. 根尖点 Apex

核心思想：骨架负责提供"某条牙根内部中心线在哪里终止"的证据，真实牙根外表面负责给出最终的解剖落点。把骨架端点作为方向证据，再回到真实外表面定位根尖点。

### 1.1 骨架提取与端点

对整颗牙 mask 做骨架化：把实心 mask 反复剥离边界体素，收缩为1体素宽、且与原形状拓扑等价（连通性、分叉数、孔洞数不变）的中心线。得到中心线后，统计每个骨架点在 26 邻域内的相邻点数：为 1 的点是端点（路径终止处），不少于 3 的点是分叉点，为 2 的是普通路径点。

对牙齿骨架化保留多根牙**从牙冠到牙根**的完整连通结构。牙根分叉与终止的拓扑被保留下来：端点是"牙根内部路径不再延伸的位置"。

### 1.2 只保留根区内的端点

用 root_filter_mask（根侧方位）过滤全部骨架端点，只保留落在根侧候选区内的端点。骨架在牙冠侧同样会产生端点（细长牙的中心线本就从根尖延伸到切缘/牙尖，在冠端自然终止），排除它们。

### 1.3 选择候选根尖

根区端点（root_filter_mask 内的骨架端点）本身已经是一批更靠近牙根的点，按照下面选择策略选出候选根尖：

1. 按候选分数（沿 root_direction 的归一化投影，越靠根端越大）把全部根区端点降序排列；
2. 从高到低检查, 如果这个点与已经选中的点的距离大于一个固定值(8个体素),那么选中它,从而排除可能存在的离的过于近的点.
3. 最多选3个候选根尖。

### 1.4 根尖落点定位（EDT 距离场版）

> **状态**：已实现于 `geometry/apex_edt_basin.py`，作为最终根尖来源；旧"终末表面帽区"保留在 `apex_finalize.py`，仅作诊断/回退。

**核心定义**：设第 k 个根的盆地为 `Ω_k`，其质心 `c_k`、PCA 根轴 `d_k`（朝根方），则

    根尖 a_k = argmax_{x ∈ Ω_k} (x − c_k) · d_k

线性泛函在有界闭集上的最大值必在边界取到，因此 `a_k` 自动落在 `∂Ω_k` 上，即**影像外尖**，与 GT 语义一致。

**执行步骤**：

1. **距离场**：对 tooth mask 做欧氏距离变换 `D(x) = min_{y∉Ω} ||x − y||`，得到每个体素的局部内切半径。
2. **分根盆地**：先从根区切出**牙根分支区**——多根牙沿 `root_direction` 逐箱统计横截面连通域数，取"连续 ≥3 箱都出现 ≥2 个足量连通域"的起始位置作为根分叉，向根方为分支区；再在分支区内以候选点为种子，对 `−D` 做 watershed，得到 `Ω_1 … Ω_K`。单个盆地过小时，改用该候选周围的局部圆柱，并加"最近候选"约束，避免串根。
3. **每盆地 PCA**：对 `Ω_k` 的体素做 PCA，取第一主轴为 `d_k` 并按 `root_direction` 定向，质心为 `c_k`。这一步取代旧方案第一步的"骨架回溯方向"。
4. **取轴向极值**：`a_k = argmax_{x∈Ω_k} (x − c_k) · d_k`。这一步取代旧方案第 4 步的"中心线一圈 + 最远 + 字典序"。
5. **置信度**：用两个无量纲量门控；不达标则标记"证据不足"、不输出该根尖：
   - 尖端半径比 `D(a_k) / max_{x∈Ω_k} D(x)` 应较小（尖细）；
   - 收削一致性 `taper_score`（沿 `d_k` 分箱后 `D` 的非递增区间比例）应较高。
6. **确定性合并**：按 1.5 的"径向升序 → 轴向降序 → z-y-x 升序"优先级去重（`merge_distance` 默认 6 体素）。

**实现参数**：`enable_edt_basin_apex=True`；`tip_radius_ratio_max=0.90`、`taper_score_min=0.30`（`require_confidence=False` 时仅作诊断）、`fallback_radial_max=12`、`merge_distance=6`。

**与中轴/骨架的关系**：中轴是 `D` 的脊，其中轴终点 `m_k ≈ a_k − D(a_k)·d_k`，即骨架端点位于外尖内部约一个尖端半径处。这解释了为什么骨架落点天生比影像外尖偏内，也说明 EDT 版在语义上更贴近 GT。

### 1.5 确定性合并

把定位成功的点按"径向升序 → 轴向降序 → z-y-x 升序"的字典序作为保留优先级去重：距离小于阈值（默认 6，体素）的点视为同一根尖的重复，每根最终只留一个。

同一解剖根尖可能产生多个邻近候选；用确定性规则（而非随机或加权评分）合并，保证结果可复现。

## 2. 牙槽骨脊顶 Alveolar Crest

核心思想：用"牙面 ↔ 骨面形态学邻接"圈出分根、分角度的冠方骨面前沿，再用表面最短路径补环，得到稳定的环状脊顶。

### 2.1 牙/颌骨邻接边界

分别提取牙、颌骨表面，把牙表面先做少量形态学膨胀（默认 2 次）再与颌骨表面相交。

### 2.2 root/angle-aware 冠方包络

得到的牙骨邻接面会顺着牙根往根方延伸很长一段，但牙槽骨脊顶要的是这个面的上沿——靠近牙冠的那一边。因此,取"每个牙根、每个周向方向上最靠冠方的一段"。具体步骤:

- 找根锚点。对 root_filter_mask（牙体内距颌骨 ≤ 2mm 的区域，近似牙根段）做连通域标记，丢掉小于 80 体素的碎块，按大小取前 4 块，每块取体素质心作为一个根锚点。多根牙在分叉以下的区域是分离的，所以通常得到多个锚点.
- 建一个横截面。垂直于牙长轴,且经过牙齿质心，把所有边界点(也就是颌骨上与牙根的距离在2体素内的点)和锚点都投影到这个横截面上。
- 每一个边界点都会被分配一个距离最近的根锚点.
- 用牙体 PCA 长轴作旋转轴，把边界点按周向角分成36个区域. 每个 (根锚点, 角度区域) 内，对于每一个点,计算从它的根锚点出发到这个点的位置在轴向冠方的距离, 取最靠前的前 25% 的点。

### 2.3 冠方前沿 + 最短路径稳定化

- **冠方前沿**：仍按"每条根 × 每个角度扇区"来整理。每个扇区里，沿牙冠方向找**最高的那一点（上包络）**，只保留距它不超过 1 个体素的点。这样得到的是一条**只在冠侧**的薄边，而不是同时包含冠侧和根侧两条边的普通边界。用"最高点"而不是"前百分之几"，是因为上沿是几何极值，跟这一格里有多少个点无关。

- **稳定化补环**：把牙颈周围分成 36 个扇形。有些区域的牙和骨之间本来就有缝、或分割断开.
  1. 每个有前沿点的格子，只挑"最靠牙冠"的那一个点作为该格的代表。
  2. 看相邻的格子（包括绕一圈回到起点的那一对）。如果两面旗之间隔的空格子不超过 3 个，就在"牙槽骨表面、且不在牙齿里"这层薄壳上，找一条把它们连起来的最短小路（最多走 48 步，允许斜着走）。
  3. **把小路补进去**：这些小路只用来把断开的环接上，不删掉原有的前沿点。所以结果 = 完整前沿 + 补的小路。

处理牙骨边界可能有缺口，导致牙槽骨嵴顶的形态会断裂。沿骨面连接断裂的缺口。

## 3. 釉牙骨质界 CEJ

核心思想（当前主流程）：**先在矢状面逐切片判定高密度釉质区域、叠合成 3D 釉质体积，再把该体积投影到牙面得到釉质覆盖区，最后绕牙长轴每角度取最根侧的覆盖点，得到落在牙面上的 CEJ 环。**

CEJ 的解剖定义是"釉质覆盖区的最根端下缘边界"，因此"每角度釉质的最根端一点"就对应该角度下的 CEJ。

### 3.1 密度自适应归一化

把一个两分量高斯混合模型（GMM）拟合到牙体 mask 内所有体素的 CT 密度上，得到两个分量：低密度分量对应牙本质（均值 μ_dentin），高密度分量对应牙釉质（均值 μ_enamel）。据此定义归一化标量：

    S' = clip((I − μ_dentin) / (μ_enamel − μ_dentin), 0, 1)

其中 I 是体素原始 CT 密度值；μ_dentin 与 μ_enamel 分别是低、高两个高斯分量的均值，即本牙牙本质与牙釉质的代表密度；μ_enamel − μ_dentin 是两峰间距；I − μ_dentin 表示该体素高出牙本质峰多少；两者相除得到该体素"从牙本质峰走向釉质峰的进度"（0=牙本质、1=釉质、0.5=两者中点）；clip 把低于牙本质峰的值截到 0、高于釉质峰的值截到 1，去除离群值。GMM 拟合时还估计了各分量的方差与权重，但这里的归一化只用到两个均值。

所以 S' 本质是对每颗牙做一次重标定：把"这颗牙自己的牙本质峰→0、釉质峰→1"。0.5 就是天然的分界。

### 3.2 逐矢状切片判定釉质区域

对每个固定 x 的矢状切片（即取 `img[:, :, x]`，得到 y-z 二维截面），在该切片的牙体截面内判定 `S' ≥ 0.5` 的像素为釉质，再做 2D 连通域筛选：把釉质像素分成若干连通块，按像素数下限过滤后对所有保留块取并集。目前只删除 size==1 的单像素点，2–5 像素的小块会被保留。逐片叠成 3D 釉质体积。

### 3.3 薄釉质补判

逐片阈值判定对很薄的釉质容易漏：CT 图像里每个体素的灰度其实是"一小块立方体里所有组织的平均"，当这个立方体正好位于釉质与牙本质（或空气）的交界上时，亮的釉质会被相邻的暗组织"稀释"，记录值落在两者之间(部分容积效应)。釉质只剩表面一两层时，这种稀释会让边缘的 `S'` 达不到 0.5，于是薄釉质被漏判。
    
- 只在"牙冠带"内、且牙面上 `S' < 0.5`（主判据未点亮）的表面点评估；牙冠带由已有釉质体素的 z 坐标 1%/99% 分位 ± 3 体素确定。
- 从表面点沿**外法向**（由平滑牙 mask 的梯度估计，并按径向朝外定向）做一维强度采样（−10…+6 体素，步长 0.5）。
- 取 [−2.5, −0.5] 区间的最大强度为 peak、[−4, −3] 区间均值为 base_in、[0.5, 1.5] 区间均值为 outside；同时满足 `peak − base_in > 80` 且 `peak − outside > 200` 时，判为"表面下存在一条薄亮层"。
- 把 peak 所在体素（仍需在牙 mask 内）补入釉质体积。

因此最终的 3D 釉质体积里会包含一部分"不满足 `S' ≥ 0.5`、但沿法向存在薄亮层"的体素。80/200 是原始 CT 值上的强度差阈值；设 `enable_thin_enamel_augmentation=False` 可关闭该步。

### 3.4 3D 连接

逐片 2D 判定在叠合后容易出现切片间断裂，闭运算能把这些缝隙补上。因此对（补判后的）体积做一次 3D 闭运算填缝。

### 3.5 绕轴取釉质根端边缘

把牙根方向当作一根"轴线"、整颗牙的质心当作原点。对每个釉质体素，从两个层面描述它的位置：(1) 只考虑这根轴线方向，沿轴线行进的距离（越往根尖方向数值越大）；（2）该体素点的位置在绕这根轴转到了哪个方向（从轴的方向看下去的水平方位角）。把一整圈 360° 平均分成 72 份（每份 5°）。每一份区域中如果有釉质，就选出"在这个区域中沿轴线最靠根尖"的那个体素，作为这个方向上的 CEJ 点。72 个方向的点连起来，就得到绕牙颈一圈的 CEJ 环。

随后对这个环做 wrap（首尾连续）中值平滑，抑制相邻角度间的抖动。

### 3.6 投影到牙面并得到最终环

上述边缘点位于釉质体积的边缘，而釉质体积相对真实牙面有内缩（部分容积效应导致最外层的 S' 未达阈值）。为让 CEJ 落在真实牙面上：

- 取牙体表面点与 3D 釉质体素；对每个釉质体素找最近的牙面点，把该牙面点标为"釉质覆盖"（等价于把内缩的釉质体积向外投到其最近牙面，自动补偿内缩）。
- 在覆盖体素的表示上，再次按3.5中提及的方式，得到最终落在牙面上的 CEJ 环。

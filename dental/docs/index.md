# 三个子任务：执行逻辑与原理

本文记录 Apex（根尖点）、Alveolar Crest（牙槽骨脊顶）、CEJ（釉牙骨质界）三个子任务的执行流程与背后的原理。

---

## 0. 共享几何信息准备

三个任务都需要统一的**牙根方向**和**哪里是根侧**的判断。这一层能够产出下列信息供三个任务复用。

### 0.1 PCA 主轴

对单牙 mask 的全部体素坐标做协方差分析，取最大特征值对应的特征向量作为**无向主轴**。

牙齿在冠-根方向上的延伸通常最长，PCA 第一主轴自然捕获该方向。但特征向量没有正负号，因此这一步无法确认哪一端是根尖的方向。

### 0.2 用颌骨给主轴定向 → 根尖方向 和 "根侧"方位（root_filter_mask）的确定

提取牙体表面，计算每个表面点到对应颌骨的距离，取距离最近的一批点（最近 15% 分位，且至少 20 点），把这些点投影到 PCA 主轴上。若投影中位数落在正侧，则根方向取 +主轴，否则取反。这个判断的依据是：**离对应颌骨最近的一批牙体表面点位于牙根侧**。

在牙体内部取"到颌骨表面距离 ≤ 2mm 的体素"，作为"根侧候选区"。这样可以把后续搜索范围圈定在根侧.

### 0.3 轴向投影范围 axis_projection

把全牙体素沿 root_direction 投影并归一化到 [0, 1]，1 表示最靠根端。

## 1. 根尖点 Apex

核心思想：**骨架负责提供"某条牙根内部中心线在哪里终止"的证据，真实牙根外表面负责给出最终的解剖落点。** 把骨架端点作为方向证据，再回到真实外表面定位根尖点。

### 1.1 骨架提取与端点

对**整颗牙** mask 做**骨架化**：把实心 mask 反复剥离边界体素，收缩为一条一个体素宽、且与原形状拓扑等价（连通性、分叉数、孔洞数不变）的**中心线**。得到细线后，统计每个骨架点在 26 邻域内的邻居数作为邻接度数：度数为 1 的点是端点（路径终止处），度数 ≥ 3 的点是分叉点，度数为 2 的是普通路径点。

对牙齿骨架化, 可以保留多根牙的**从牙冠到牙根**的完整连通结构。牙根分叉与终止的拓扑被保留下来：端点是"牙根内部路径不再延伸的位置"，也是牙根数量的依据来源。

### 1.2 只保留根区内的端点

用 root_filter_mask（根侧方位） 过滤全部骨架端点，丢弃不落在牙根侧或骨外的毛刺端点。牙冠侧同样会产生骨架毛刺端点，它们不是根尖证据；先用"贴近骨 → 根侧"这一约束把它们排除。

### 1.3 高召回 top 集

对根区端点按沿 root_direction 的投影排序，取投影靠前的前 60%（数量夹在 [3, 24] 之间）作为召回集合。

这是**召回导向**的取舍：宁可多留候选，也不要在入口处就漏掉某条根。每个端点的候选分数暂取其归一化投影（越接近 1 越靠根端）。

### 1.4 自适应聚类得到候选

对召回集合做轻量 k-means，从较大的 K 向较小的 K 尝试：每个簇选分数最高的端点作为一个候选；若某次 K 下所有候选两两间距都 ≥ 8（体素）则接受该结果（允许额外候选），否则继续减小 K 合并。

K 的自适应让"根数"由**端点空间分布 + 最小分离度**共同决定，而不是硬性指定。`use_root_count_prior`（默认开启）额外用 FDI 的 `expected_root_count` 约束 K 的搜索范围，并允许 +1，因为该先验只是解剖预期而非硬约束（根融合、变异、分割误差都会改变真实根数）。

### 1.5 终末表面帽区定位（把候选修正到真实牙根尖端）

候选来自骨架内部，需要落到真实牙根外表面上。做法：

1. **构造根区表面**：先对整牙提表面，再与 root_filter_mask 相交。先提整牙表面再相交，是为了避免把"牙冠/牙根的人为切面"误当成真实外表面。
2. **归属隔离**：把每个根区表面点指派给最近的骨架候选（Voronoi 式归属），从而隔离不同牙根，避免跨根吸附。
3. **估计局部终末方向**：从候选沿骨架向牙体内部回溯最多 8 步，用"端点减回溯点"作为该根自己的终末伸出方向；回溯不可用时退化为"候选减所属表面质心"，再退化为全局 root_direction，并统一翻转到根方向一侧。
4. **切出终末帽区**：以候选为原点、终末方向为局部轴，在所属根表面点中取轴向落在 [−1.5, 前向距离] 且径向不超阈值的点，作为"终末表面帽区"。
5. **帽区内选点**：先只保留最贴近局部中心线的一圈（径向 ≤ 最小径向 + 0.75），再在该圈内取终末方向最靠前的一点；若并列按 z-y-x 升序打破平局。

**为什么这样选**：单点骨架端点不足以定位解剖根尖；"真实外表面 + 一小段连续骨架路径 + 帽区约束"能给出稳健的终末落点。而"先中心线、再终末最前"的规则既避免选到偏侧的毛刺表面，又保证结果足够靠近末端。只有形成帽区的候选才进入最终输出，未形成者只保留调试信息。

### 1.6 确定性合并

把定位成功的点按"径向升序 → 轴向降序 → z-y-x 升序"的字典序作为保留优先级去重：距离小于阈值（默认 6，体素）的点视为同一根尖的重复，每根最终只留一个。

同一解剖根尖可能产生多个邻近候选；用确定性规则（而非随机或加权评分）合并，保证结果可复现。

### 输出

每个牙根一个解剖根尖点、根数量、以及骨架/候选/帽区等中间信息（供可视化与调试）。

## 2. 牙槽骨脊顶 Alveolar Crest

核心思想：**用"牙面 ↔ 骨面形态学邻接"圈出分根、分角度的冠方骨面前沿，再用表面最短路径补环，得到稳定的环状脊顶。**

### 2.1 牙/颌骨邻接边界

分别提取牙、颌骨表面，给出两种邻接边界：

- **方案 A（严格）**：颌骨表面中，一步邻域内存在牙表面体素的点。最严格、不依赖距离阈值，但牙骨间若有 1~2 体素空隙会断裂，仅作对照。
- **方案 B（canonical）**：把牙表面先做少量形态学膨胀（默认 2 次）再与颌骨表面相交。

**为什么用 B**：CBCT 分割中牙与骨之间常有 1~2 体素空隙，用固定距离阈值会对 spacing 和牙骨间距敏感；方案 B 用"拓扑邻接 + 小量膨胀"既避开固定阈值，又容忍轻微空隙。

### 2.2 root/angle-aware 冠方包络

原始邻接边界会沿牙根方向延伸较长，这不是错误，但我们真正要的是"每个牙根、每个周向方向上最靠冠方的一段"。做法：

- 从 root_filter_mask 的连通分量提取**根锚点**：每个足够大的连通根区取几何质心作为一个代表点（不是解剖根尖，只作分组参考），最多 4 个；单根或分不开时退化为"整牙质心一个锚点"。它锚定的是**该根区的局部参照原点**——既用于把每个邻接边界点归属到"平面上离它最近的根"，也作为该根内周向角与冠方投影的计算中心。
- 用牙体 PCA 长轴（符号对齐 root_direction）作旋转轴，把邻接边界点按周向角分 36 个 bin。
- 每个 (根锚点, 角度 bin) 内，只保留冠方投影最靠前的前 25% 的点。

分根处理保证磨牙不会只选到某一根上的 crest；结果是 root-aware + angle-aware 的**非平面冠方包络**。

### 2.3 牙槽窝支撑骨面候选

以"2.2 包络 ∩ 颌骨表面 ∩ 非牙体"作为 seed，形成牙槽窝支撑骨面点集。默认不做沿骨面的额外扩展（扩展步数 0），即候选等价于冠方包络落在颌骨表面上的支撑点。

**为什么**：只允许从冠方包络出发，禁止从完整骨面按"离牙距离"全局挑选——旧做法会把薄骨区拉回牙根方向。默认不扩展也是同理，避免向根方扩入。

### 2.4 冠方 frontier + 最短路径稳定化

- **09 冠方 frontier**：每个 (根锚点, 角度 bin) 内保留冠方投影 top 35%，每 bin 最多 8 点。得到的是**冠侧单边**的边界，而非同时含冠侧与根侧两条边的普通边界。
- **10 稳定化**：以 09 的完整结果为基础；每个有点的 bin 取最冠一点作为 anchor；对相邻（含首尾 wrap）且间隔不超过约 3 个空 bin 的 anchor 对，在"颌骨表面且非牙体"上做 18 邻域受限 BFS，求不超过 48 步的最短路径，把路径体素并入结果。

**为什么 10**：普通表面边界的角向缺口会让环状脊顶断裂；10 用表面最短路径在相邻角区之间桥接补洞。它是"补洞/桥接"而非"筛选精修"，因此稳定化结果包含 09 的全部内容。

### 输出

环绕牙根的稳定化环状脊顶候选点带（评估按 HD95 与 GT 比较），以及 07/07B/08/09 各中间层供可视化。

## 3. 釉牙骨质界 CEJ

核心思想（当前主流程）：**先在矢状面逐切片判定高密度釉质区域、叠合成 3D 釉质体积，再把该体积投影到牙面得到釉质覆盖区，最后绕牙长轴每角度取最根侧的覆盖点，得到落在牙面上的 CEJ 环。**

CEJ 的解剖定义是"釉质覆盖区的最根端下缘边界"，因此"每角度釉质的最根端一点"就对应该角度下的 CEJ。

### 3.1 密度自适应归一化

对牙体 mask 内的 CT 密度拟合两个高斯（牙本质峰 μ_dentin、釉质峰 μ_enamel），定义归一化标量：

    S' = clip((I − μ_dentin) / (μ_enamel − μ_dentin), 0, 1)

**为什么**：固定灰度阈值（如 2350）跨病例/扫描不可比——不同病例的两个峰位差异很大。GMM 把每颗牙自己的"牙本质峰 / 釉质峰"分别映射到 0 / 1，使 S' 成为逐牙自适应的可比标量，0.5 即天然分界。

### 3.2 逐矢状切片判定釉质区域

对每个固定 x 的矢状切片，在该切片的牙体截面内判定 `S' ≥ 0.5` 的像素为釉质，再做 2D 连通域筛选，保留所有不小于 6 像素的区域（**不**逐片只取最大，避免切片间跳变），逐片叠成 3D 釉质体积。

### 3.3 3D 连接

对叠合后的体积做一次 3D 闭运算填缝，再保留最大的 3D 连通域。

逐片 2D 判定在叠合后容易出现切片间断裂，必须做一次 3D 连续性处理才能得到连续体。

### 3.4 绕轴取釉质根端边缘

以 root_direction 为轴、牙体质心为原点构造正交基，给每个釉质体素算周向角与轴向投影，分 72 个环向 bin；每个 bin 内取**轴向投影最靠根方**的一个釉质体素，作为该角度的 CEJ 点。

这就是把 CEJ 的"釉质覆盖的根端边界"定义直接转成几何操作。随后可选对环做 wrap（首尾连续）中值平滑，抑制相邻角度间的抖动。

### 3.5 投影到牙面并得到最终环

上述边缘点位于釉质体积的边缘，而釉质体积相对真实牙面有内缩（部分容积效应导致最外层的 S' 未达阈值）。为让 CEJ 落在真实牙面上：

- 取牙体表面点与 3D 釉质体素；对每个釉质体素找最近的牙面点，把该牙面点标为"釉质覆盖"（等价于把内缩的釉质体积向外投到其最近牙面，自动补偿内缩）。
- 在覆盖体素的表示上，再次按 72 环向 bin、每 bin 取最根侧的覆盖牙面点，得到最终落在牙面上的 CEJ 环。

### 输出

归一化参考值（μ_dentin / μ_enamel / S' 阈值）、3D 釉质体积、牙面覆盖率、最终 CEJ 环点与环曲线，以及中间层供可视化。评估取最终环与 GT 标记的 HD95（过滤缺失角度后）。

## 附：三者横向对比

| 维度 | Apex | Alveolar Crest | CEJ |
|---|---|---|---|
| 目标 | 每个牙根一个解剖根尖点 | 环绕牙根的冠方骨面前沿曲线 | 环绕牙颈的釉质下缘曲线 |
| 输入 | tooth_mask (+jawbone) | tooth_mask + jawbone_mask | image + tooth_mask |
| 关键证据 | 骨架端点 + 终末表面帽区 | 牙-骨形态学邻接 | 逐片釉质判定 + GMM 自适应归一化 |
| 多根处理 | 骨架分叉 + 端点聚类 | root_filter_mask 连通域根锚点 | 环向分 bin（不显式分根） |
| 主要输出 | 每根一个根尖点 | 稳定化环状脊顶候选带 | 投影到牙面的 CEJ 环 |
| 评估 | 欧氏距离 + SDR@0.5mm | HD95 | HD95（过滤缺失角度后） |
| 主几何模块 | skeleton / apex_candidate / apex_finalize | alveolar_crest | cej_sagittal / cej_surface / cej_normalization |

# 三个子任务：执行逻辑与原理

本文记录 Apex（根尖点）、Alveolar Crest（牙槽骨脊顶）、CEJ（釉牙骨质界）三个子任务的执行流程与背后的原理。

---

## 0. 共享几何信息准备

三个任务都需要统一的**牙根方向**和**哪里是根侧**的判断。这一层能够产出下列信息供三个任务复用。

### 0.1 PCA 主轴

对单牙 mask 的全部体素坐标做协方差分析，取最大特征值对应的特征向量作为**无向主轴**。

牙齿在冠-根方向上的延伸通常最长，PCA 第一主轴自然捕获该方向。

### 0.2 用颌骨给主轴定向 → 根尖方向 和 "根侧"方位（root_filter_mask）的确定

提取牙体表面，计算每个表面点到对应颌骨的距离，取距离最近的一批点（按距离取最近的 15% 分位；若不足 20 个，则补足到最近的 20 个），把这些点投影到 PCA 主轴上。若投影中位数落在正侧，则根方向取 +主轴，否则取反。这个判断的依据是：**离对应颌骨最近的一批牙体表面点位于牙根侧**。

在牙体内部取"到颌骨表面距离 ≤ 2mm 的体素"，作为"根侧候选区"。这样可以把后续搜索范围圈定在根侧.

### 0.3 轴向投影范围 axis_projection

把全牙体素沿 root_direction 投影并归一化到 [0, 1]，1 表示最靠根端。

## 1. 根尖点 Apex

核心思想：骨架负责提供"某条牙根内部中心线在哪里终止"的证据，真实牙根外表面负责给出最终的解剖落点。把骨架端点作为方向证据，再回到真实外表面定位根尖点。

### 1.1 骨架提取与端点

对整颗牙 mask 做骨架化, 得到一个二维中轴面

### 1.2 只保留根区内的端点

用 root_filter_mask（根侧方位）过滤全部骨架端点，只保留落在根侧候选区内的端点。

### 1.3 根代表点

对于每一个牙根,选出一个牙根代表点. 它表示牙齿的骨架在这个位置终止.

1. 按候选分数（沿 root_direction 的归一化投影，越靠根端越大）把全部根区端点降序排列；
2. 从高到低检查, 如果这个点与已经选中的点的距离大于一个固定值(8个体素),那么选中它,从而排除可能存在的离的过于近的点.
3. 根据根尖数量的先验值, 代表点数不超过根尖先验值+1.

### 1.4 根尖落点定位（种子分区 + EDT 中轴 + SDF 零点）

**核心思想**：先由骨架候选 + EDT 峰确定"每根一个种子"，再把根区按最近种子轴分区；每支取局部 EDT 中轴，最后沿中轴求整牙 SDF 的最根方零交点。
EDT（欧氏距离变换）是一张距离图, 这张图上牙体内每个体素的值，等于它到最近牙面的距离，单位是体素。

1. 种子选取
在根代表点的基础上, 如果选出的总数少于根尖数量的先验值, 则从分支区中的EDT峰中补充, 仅选择与根代表点距离不少于8体素的EDT峰作为补充种子, 优先选择靠近根的EDT峰. EDT峰的位置在牙齿内部半径最大的内切球球心.

2. 最近轴分区
每个种子定义一条**局部轴**：从牙体质心指向该种子，并使得轴的方向始终是指向根的. 对于根侧的每一个体素, 计算它到每条局部轴的垂直距离, 为每一个体素分配一个垂直距离最近的轴.
这样根区中分属不同根的体素就可以彼此区分.

3. 局部EDT中轴
对于每一个根的分区, 计算其中的每个体素到**局部轴**的投影, 沿轴每隔一段距离(2体素), 选取EDT最大的体素作为这一层的中心(这一层最大的内切圆圆心). 各层中心按投影排序，连成折线, 然后平滑, 得到一个局部的EDT中轴.

4. SDF 零点
SDF表示整颗牙的有符号距离场，牙内为负、牙外为正、牙面为 0。
沿中轴从冠方往根方采样 SDF值, 找SDF值“由负变正”的相邻两点, 在两点之间线性插值得到根尖点. 若中轴末端还在牙内, 则沿末端切向外推继续采样(至多采样12体素).

## 2. 牙槽骨脊顶 Alveolar Crest

核心思想：牙槽骨嵴顶是牙槽骨沿冠方方向的边缘。先定出与当前牙相邻的骨表面，再以"往牙根有牙槽骨区域, 且往牙冠方没有牙槽骨区域"为基准, 筛出冠方向的边缘带，最后绕牙长轴逐角度取最冠方点，得到嵴顶线。

### 2.1 牙邻接骨面

先从颌骨(牙槽骨)分割 mask 里取出骨表面。这里的"表面"指骨内贴着"骨/非骨"交界的那一层体素。做法是：对颌骨 mask 做一次 6 邻域腐蚀，只保留上下前后左右 6 个邻居都在牙槽骨区域内的体素(保留下来的就是不与牙根邻接的牙槽骨)。把保留的部分去掉，剩下的自然就是牙槽骨的表面，也就是至少有一个方向上不是牙槽骨的体素。

然后，对当前牙 mask 做 δ 体素膨胀（默认 δ = 2，用于容纳牙周膜间隙与分割误差），再与表面相交，得到牙邻接骨面。
这种做法可以把候选区域限制在这颗牙周围的骨表面，排除远离牙的骨板、邻牙区域。

### 2.2 牙槽骨上边缘

牙槽骨包着牙根，它的上沿（靠牙冠的那一条边）就是牙槽嵴顶。如果一个骨面点往牙根方向移动属于牙槽骨，往牙冠方向移动则不是, 那么说明它位于牙槽骨的上边缘.
按照这个规则, 检查2.1得到的所有骨面点。检查的移动距离为1体素.
骨内部的表面、牙根侧壁、根尖附近的端面都不满足"往牙冠方向离开牙槽骨区域"，因此会被自动排除。

### 2.3 绕牙长轴逐方向取最高点

2.2 得到的是环绕牙颈的一个带状区域。要得到嵴顶线，需要在每个方向上只保留最高(最靠近牙冠方向)的那个点。

把绕牙长轴的一周分成 72 个等角扇区，每 5° 一个。对 2.2 得到的每一个点：以牙体质心为原点、牙长轴为轴，算出它绕轴转到的方位角，归入对应扇区；同时算出它沿牙冠方向的高度。每个扇区里只保留高度最大的点，其余丢弃。保留下来的点合起来就是嵴顶线。

## 3. 釉牙骨质界 CEJ

核心思想：**在牙齿表面的 3 体素薄层上算一个逐牙 Otsu 阈值，用它在矢状面逐切片判定釉质、叠成 3D 釉质体积，然后绕牙长轴每角度取最靠根侧的釉质体素，最后把每个点投影到最近的牙面。**

CEJ 的解剖定义是"釉质覆盖区的最根端下缘边界"，因此"每角度釉质的最根端一点"就对应该角度下的 CEJ。

### 3.1 表面薄层上的 Otsu 阈值

1. **表面薄层**：对牙体 mask 做欧氏距离变换（EDT），得到每个牙体体素到最近"非牙体"体素的距离（体素单位）。取 `shell = tooth_mask & (EDT <= 3)`，即从牙面往里约 3 体素厚的一圈。0.25 mm 体素间距下约为 0.75 mm。
2. **Otsu 阈值**：只在这条薄层内的原始强度上算 Otsu，得到一个把"薄层里的高密度成分"和"低密度成分"分开的阈值 t。

Otsu阈值假设灰度图中存在前景和背景两个类别, 算法的目标是选取让两类之间差异最大、也就是类间方差最大的那个阈值。

### 3.2 逐矢状切片判定釉质区域

对每个固定 x 的矢状切片（即取 `img[:, :, x]`，得到 y-z 二维截面），在该切片的牙体截面内判定 `I >= t` 的像素为釉质，再做 2D 连通域筛选：把釉质像素分成若干连通块，删除小于 4 像素的块（即去掉 1/2/3 像素的碎块），其余取并集。逐片叠成 3D 釉质体积。

### 3.3 3D 釉质体积

逐片 2D 结果直接叠合成 3D 釉质体积.

### 3.4 绕轴分角度取最根点

把牙根方向当作一根"轴线"、整颗牙的质心当作原点。对每个釉质体素，从两个层面描述它的位置：(1) 沿轴线行进的距离（越往根尖方向数值越大）；(2) 该体素绕这根轴转到了哪个方向（从轴的方向看下去的水平方位角）。把一整圈 360° 平均分成 72 份（每份 5°）。每一份区域中如果有釉质，就选出"在这个区域中沿轴线最靠根尖"的那个体素，作为该方向的 CEJ 候选点。

### 3.5 投影到最近牙面

上述候选点位于釉质体积内部/边缘，而釉质体积相对真实牙面有内缩（部分容积效应导致最外层体素达不到阈值）。

1. 取牙面点：对牙体 mask 做一次 6 邻域腐蚀，得到最外一层的牙体体素（表面点仍属于牙齿本身）。
2. 使用 KD-tree (一种空间索引)维护每一个牙体体素到与其最近的表面点之间的关系.
3. 查询最近点：对每个候选点返回欧氏距离最近的表面点的索引；再通过索引取回该表面点坐标，作为投影后的 CEJ 点。

替换后的点即最终 CEJ 点，按角度顺序连成 CEJ 环。
